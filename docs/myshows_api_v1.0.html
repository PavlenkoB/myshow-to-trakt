MyShows.me API v2.0

CurrentAPI based on JSON-RPC 2.0 with OAuth 2.0 as authorization.

MyShows.ru API v1.8 (deprecated)

Работа с профилем

Авторизация

 https://api.myshows.me/profile/login?login=<login>&password=<md5(password)>
Пример
https://api.myshows.me/profile/login?login=demo239&password=0f25bd0ff7b9cfd3ebbec99f55a34b61 		200 — Аутентификация произведена
403 — Имя пользователя или пароль не подошли
404 — Пустые параметры

Авторизация через ВКонтакте

 https://api.myshows.me/profile/login/vk?token=<token>&userId=<userId>
Пример
https://api.myshows.me/profile/login/vk?token=a8f5f167f44f4964e6c998dee827110c&userId=1 		200 — Аутентификация произведена
403 — Не прошла авторизация через соц. сеть
404 — Переданы не все параметры

Синхронизация всех просмотренных эпизодов (полная)

 https://api.myshows.me/profile/shows/<show-id>/sync?episodes=<episode-id>,<episode-id>
Пример
https://api.myshows.me/profile/shows/142/sync?episodes=16388,16387,16386 		401 — Требуется авторизация
404 — Сериал не найден
200 — ОК

Синхронизация всех просмотренных эпизодов (delta)

 https://api.myshows.me/profile/shows/<show-id>/episodes?check=<episode-id>,<episode-id>&uncheck=<episode-id>,<episode-id>
Пример
https://api.myshows.me/profile/shows/142/episodes?check=16388,16387&uncheck=16386 		401 — Требуется авторизация
404 — Сериал не найден
500 — Один из параметров check или uncheck отсутствует
200 — ОК
