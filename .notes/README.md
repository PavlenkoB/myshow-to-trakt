# LLM Knowledge Base Root

Store atomic learnings here. Max 1024 tokens per file. Use hybrid XML/Markdown format.

## Child Directories

- `database/`: Database, JPA, Migrations, and Hibernate learnings.
- `testing/`: Integration test setups, REST Assured, and test container issues.
- `domain/`: Business concepts, entities, and glossary.
- `architecture/`: High-level system design and rules.
- `agent-orchestration/`: Rules for managing sub-agents and worktrees.
- `templates/`: Standard XML templates for notes.

**Navigation Rule:** Read the `README.md` in a child directory to see further sub-divisions.
**Creation Rule:** You may create new subdirectories at your discretion when a topic becomes cluttered. You MUST update this list if you do.
**Self-Correction Rule:** If you discover any note in this tree is incorrect or outdated, you MUST overwrite it with the corrected information.
